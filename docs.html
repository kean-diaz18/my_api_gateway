PHP API Gateway Documentation

This gateway routes requests and enforces API key validation and rate limiting.

Authentication

Pass your API key in the header:

X-API-Key: your_api_key_here

Rate Limiting

Each key is limited to 10 requests per 60 seconds.

Endpoints

  • /api/users - Get all users
  • /api/products - Get all products
  • /api/dashboard - Aggregated users and products

Example Request (cURL)

curl -H "X-API-Key: key123" http://localhost/gateway.php?request_path=dashboard
